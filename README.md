# K-Means Image Segmentation

Provide coins.png as a grayscale example and zein.jpg as a color example. The notebook compares pixel clustering with 2 and 10 clusters.

Notebooks: [kmeans-image-segmentation.ipynb](kmeans-image-segmentation.ipynb)

From this directory, use a fresh Python 3.11 environment:

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```
